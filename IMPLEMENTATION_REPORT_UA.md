# Результат перевірки й продовження роботи

Перевірено попередні незакомічені зміни, їх збережено. AGENTS.md у репозиторії
та батьківських каталогах не знайдено. Робочу БД, секрети та конфігурацію
з секретами не відкривали; справжнього бота не запускали.

## Реалізація

- Початкове меню з трьома напрямами, допомогою та єдиною підтримкою.
- Вибір співфінансування, пояснення й підтвердження інформаційного сценарію.
- Меню гранту, три тематичні розділи, 11 підрозділів та збережений FAQ.
- Статичне меню із заміною при відмові редагування й повторною доставкою.
- Персональне збереження вибору й чернеток у SQLite, сумісні міграції.
- Анкета підтримки з ПІБ, компанією/ФОП або незареєстрованим бізнесом,
  телефоном, email, перевіркою, редагуванням і явним надсиланням.
- Контекст гранту й вихідного розділу в зверненні, картці спеціаліста та листі.
- Права доступу, доставка, переписка, закриття й повернення до меню збережені.
- Старі кнопки безпечно обробляються; старі організації й звернення читаються.
- Каталог нормативного контенту та прив’язок FAQ; адміністративне редагування
  FAQ зберігається після перезапуску. Додано перевірку заголовків розділів
  відповідно до UTF-16 та обмежень клієнтського меню.

## Перевірки

`python3 -m unittest discover -s tests`: **186 тестів, OK**.
Початкова перевірка: 185 тестів, OK; додано регресію невалідних заголовків
налаштовуваного каталогу. `git diff --check` та перевірка індексу — без помилок.
У тестах Python 3.14 є ResourceWarning щодо незакритих SQLite-з’єднань
та об’єкта HTTPError; це залишається обмеженням тестового прибирання ресурсів.

Автономні сценарії перевіряють дев’ять поєднань, усі підрозділи, повернення,
зміну вибору, перезапуск, розділення користувачів, підтримку без гранту,
незареєстрований бізнес, редагування й скасування, старі дані та кнопки,
повідомлення про закриття, збій редагування/доставки та збереження FAQ.

Початкові спроби підписати коміт завершилися помилкою GPG `No secret key`
для `roboaltic <roboaltic@users.noreply.github.com>`. Після окремого дозволу
замовника створено непідписаний коміт `64dd9db` — «Перебудовано навігацію
грантів і звернення до підтримки»; звичайний push в `origin/main` успішний.
Документація оформлюється окремим непідписаним комітом із наступним звичайним
push. Налаштування підпису Git не змінювали; підпис вимкнено лише для цих команд.
Force push не використовувався. Остаточні хеші та результат другого push
наведено в повідомленні про завершення роботи.

## Запуск і ручна перевірка

Linux: `./START_LINUX.sh` або `python3 main.py` у графічній сесії з Tkinter.
Команди наведені для користувача; під час роботи їх не виконували.
Повний сценарій та створення окремої тестової копії — у
[MANUAL_CHECK.md](MANUAL_CHECK.md). Копія повинна містити каталог `content`.

Коротко: `/start` → напрям → співфінансування → підтвердження → підрозділ →
підтримка → анкета → перевірка → редагування → надсилання → відповідь спеціаліста →
закриття → повернення в меню гранту. Повторити без вибору гранту, з кнопкою
незареєстрованого бізнесу, зі скасуванням, після перезапуску та другим клієнтом.
